## 简介（短版）

同时开很多 DSH 会话，最怕任务早就跑完了，人还在等。

dsh-task-notice 把每个会话的完成提醒放到窗口右上角：完成卡片、按天台账、未读计数，拖到顺手的位置，点一下回到会话。

安装：`dsh plugin add dsh-task-notice`

## 简介（完整版）

同时开很多 DSH 会话，最怕任务其实早就跑完了，人还在等，或者干脆忘了回去看。

dsh-task-notice 把「完成」从某个会话里拿出来，放到整个窗口都能看到的地方：

- 所有会话的完成都能看到，不只眼前这一个
- 完成卡片写清项目、会话、你的问题和用时，点一下直接跳回会话
- 完成、失败、停止、阻塞分开说，失败会带上原因
- 按天分组的完成台账，未读高亮；顶部显示还有几个任务在跑
- 铃铛、面板标题、完成卡片都能拖动；靠近边缘面板自动翻面，位置会记住
- 两声短铃，完成和失败不同音色；窗口在后台还能走系统通知，都有开关
- 记录只留在本机，最近 100 条，重启还在；子代理默认不吵

安装：

```bash
dsh plugin add dsh-task-notice
```

也可以在 DSH 的插件对话框里粘贴包名安装。
